Speeds

Pan / tilt reference and limits

No endstops: jog each axis to a visual reference (e.g. barrel level, pointing straight ahead) and set zero. Then jog to each end of the safe travel and set the limits.

Loader stroke

Jog the rack fully back and set rest. Jog forward until a dart would be pushed into the flywheels and set front. Then jog back to just before the flywheels grab the dart and set ready: the loader waits there with the next dart (fully back only when the magazine is empty). "Test stroke" runs one slow push-and-return (disarmed only).

Crosshair (where darts land)

Fire at a target, then click "Pick impact" and click where the dart hit in the video. The crosshair moves there.

Field of view

Needed for click-to-aim and later for the computer vision. Auto: click one textured spot (a corner, text, a poster) near the centre; the turret steps across and tracks it, then fits the lens. Manual: turn by a known angle and click the same spot twice.
